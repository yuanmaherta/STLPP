# Renewa
Renewa – Digital Contract Renewal Evaluation System adalah aplikasi berbasis web yang dikembangkan untuk mendigitalisasi proses evaluasi dan perpanjangan kontrak karyawan PKWT di PT Hutama Karya (Persero). Sistem ini dirancang untuk menggantikan proses manual berbasis dokumen/Excel menjadi proses digital yang lebih terstruktur, efisien, dan terdokumentasi.

> Sebelumnya dikenal dengan nama STLPP.
